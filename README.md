# FakeXMB 🎮

> The classic PS3 aesthetic adapted for fluid horizontal navigation in Batocera..

The **FakeXMB** theme was created to capture the visual essence of the official PlayStation 3 XMB. As the name suggests, it's a clever adaptation: it maintains the iconic look and atmosphere of the original console, but uses **exclusively horizontal navigation**, ensuring lightness and full compatibility.

The theme features a detailed information bar at the top and, in this version, displays black and white logos in the system view, giving the interface a much more elegant, modern, and sophisticated look.

🎨 Color Customization > FakeXMB isn't limited to a single look. Choose the one that best matches your setup from the 10 included color variations, allowing you to switch between vibrant tones or more subdued themes directly in the system settings.

FakeXMB is a free theme and can be used on your preferred system. Have fun!

## ✨ Highlights
- **Faithful Aesthetics:** Visuals inspired by the PS3 interface with a focus on the horizontal bar.

## 📥 Installation

1. Download the files from this repository.
2. Transfer the `FakeXMB` folder to your system's themes directory:
`/share/themes/` or `/userdata/themes/`
3. In the Batocera menu, go to:

**Interface Settings > Theme** and select **FakeXMB**.

## 🛠️ Requirements
- **Batocera.linux** system (or systems compatible with EmulationStation).
- Recommended for widescreen displays (16:9).
